# ConversorArquivos
🧾 Conversor de Arquivos TXT para PDF

Este é um pequeno aplicativo em Python que converte arquivos .txt em arquivos PDF, salvando-os automaticamente na pasta Downloads do usuário.
A interface foi construída com Tkinter, permitindo selecionar múltiplos arquivos de texto e convertê-los com apenas um clique.

🚀 Funcionalidades

Interface gráfica simples com Tkinter

Seleção de múltiplos arquivos .txt

Conversão automática para PDF usando FPDF

Salvamento automático dos PDFs na pasta Downloads

Exibição de mensagens de sucesso e erro

🧰 Bibliotecas utilizadas
Biblioteca	Função
tkinter	Criação da interface gráfica (botões, janelas e mensagens)
filedialog e messagebox (do tkinter)	Seleção de arquivos e exibição de mensagens
fpdf	Criação e formatação dos arquivos PDF
os	Manipulação de caminhos e diretórios do sistema operacional
